# Espacio del Gamer

Doce juegos HTML originales, cada uno con su propia mecánica, música adaptativa y efectos de sonido sintetizados.

Abre `index.html` para jugar. No necesita instalación ni dependencias.

- `games/`: los 12 juegos
- `shared/audio.js`: motor de audio (música por capas, efectos, reverberación)
- `shared/engine.js`: niveles, estrellas, menús y bucle de juego
