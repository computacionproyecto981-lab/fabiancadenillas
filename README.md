# Espacio del Gamer

Doce juegos HTML originales, cada uno con su propia mecánica, música adaptativa y efectos de sonido sintetizados. No hay menú principal: cada juego se abre con su propia dirección.

| Corte Cósmico | `games/corte.html` |
| Derrape | `games/derrape.html` |

- `shared/audio.js`: motor de audio (música por capas, efectos, reverberación)
- `shared/engine.js`: niveles, estrellas, pantallas y bucle de juego
